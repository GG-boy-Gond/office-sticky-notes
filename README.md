# 桌面便签 · Office Notes

重新编写的本地桌面便签，界面署名 **Powered by 小王**。参考 xhznl-todo-list 的功能和透明便签交互，代码按窗口、数据、系统服务和界面拆分。使用 JavaScript、Electron 和标准 HTML/CSS，无前端构建步骤。

## 运行

推荐双击项目根目录的 **启动便签.cmd**。生成可运行版本后，也可使用 `outputs/启动桌面便签.cmd`。

源码启动：

```sh
npm ci
npm start
```

需要 Node.js 22 或更新版本。项目的安装脚本会将 Electron 运行组件下载到本地缓存。如安装时禁用了脚本，可以手动执行：

```powershell
$env:electron_config_cache = "$PWD\.cache\electron"
node node_modules/electron/install.js
```

此项目不依赖 Java、JDK、Maven 或 Gradle。`package-lock.json` 固定依赖版本；不需要降级电脑上的 Node.js。

## 功能与操作

| 功能           | 操作                                                                |
| -------------- | ------------------------------------------------------------------- |
| 新建           | 点击列表空白、写一条新便签，或 Ctrl N                               |
| 编辑           | 单击任务文字，停止输入后自动保存；Enter 确认                        |
| 取消本次编辑   | Esc；自动保存过的内容也会还原                                       |
| 删除待办       | 编辑时点击 ×；清空后确认也会删除                                    |
| 完成           | 双击任务文字，或点击右侧 ✓；有完成动画                              |
| 排序           | 拖动左侧手柄，顺序立即保存；手柄获得焦点后也可 Alt ↑ / ↓            |
| 完成历史       | Done 页按今天、昨天和具体日期分组                                   |
| 恢复、删除历史 | Done 页点击记录后选择 ↶ 或 ×                                        |
| Excel 导出     | 顶部导出按钮或 Ctrl E，含 todo list 和 done list 两张表             |
| 隐藏           | 顶部隐藏按钮；点击托盘或重新启动程序显示                            |
| 鼠标穿透       | 顶部锁按钮；悬停工具栏或托盘菜单可解除                              |
| 开机启动       | 设置或托盘菜单中切换，默认关闭                                      |
| 位置记忆       | 拖动窗口、调整尺寸后自动保存；屏幕断开时纠正到可见区域              |
| 更新           | 设置中检查更新；配置自己的 HTTPS 更新源后自动检查、下载，确认后安装 |
| 旧数据迁移     | 设置 → 迁移旧便签 → 导入原版 JSON；合并而不覆盖，重复导入自动去重   |

项目保留原版的无边框、透明窗口、托盘、开机启动、系统导出通知和项目参考链接。原版未实现的“贴边自动收起”不属于本次复刻范围。

## 背景与文字外观

打开右上角设置 → **背景与文字**，可以选择背景颜色、本地背景图片，分别调节背景和任务文字透明度。预览中的棋盘格代表透明区域，拖动滑块立即预览，松开后自动保存。

- **字体大小**：拖动设置中的滑块，在 **10–36 px** 之间调整，默认 **14 px**。待办、完成记录、编辑框和预览同步变化，行高随字号调整，长任务自动换行；设置面板文字保持原来的大小。松开后自动保存，重启后保留。

- **只显示文字**：背景透明度设为 **0%**，任务文字透明度设为 **100%**。鼠标移出便签后隐藏标题、工具栏和其他操作提示；移入后恢复操作按钮。键盘操作时也会保留相应控件。
- 两个滑块均为 0% 完全透明、100% 完全不透明。背景透明度同时控制颜色、图片和边框，不影响任务文字；设置面板始终保持清晰，文字设为 0% 后仍可恢复。
- 本地图片支持 PNG、JPG、WebP、BMP，采用居中铺满方式显示；图片不超过 20 MB、4000 万像素，保存时最长边缩放至 1920 像素。图片副本保存在 `notes.json` 的外观设置中，原图移动或删除不会影响显示。
- 点击图片旁的「移除」恢复纯色背景。颜色、图片、两项透明度都会在重启后恢复；旧版便签数据自动补充默认外观，保留全部任务。

原版 JSON 通常位于原应用用户目录下的 `data.json` 或 `data-dev.json`。导入只读取选中的文件，不会修改原文件。

```text

    store.cjs       数据模型、任务操作、原子写入、备份和导入

    export.cjs      Excel 工作簿生成
    system.cjs      托盘、开机启动、文件选择、系统通知
    updates.cjs     更新源配置和更新生命周期
  preload/
    index.cjs       仅向界面暴露固定的业务接口
  renderer/
    index.html     语义化界面
    styles.css     布局和样式
    app.js         编辑状态、保存队列、列表交互和动画

outputs/           Windows 可运行版本、验证截图和结果
work/              隔离的测试数据，不混入真实便签
```

## 数据与可靠性

- 项目启动入口统一使用项目根目录的 `data`。直接打开安装版 exe 时使用系统应用数据目录；如需沿用项目数据，请使用启动入口或传入 `--data-dir=绝对路径`。
- `notes.json` 是当前数据，`notes.backup.json` 是上一次成功提交前的数据。
- 主进程是唯一写入者。完成、恢复和排序都作为一次完整提交保存，界面不会直接读写文件。
- 写入临时文件并同步后替换主文件；写入失败会在界面显示错误，不会把失败状态当成已保存。
- 主文件损坏时尝试恢复备份，保留 `.damaged-*` 文件，并显示恢复提示；无可用备份时停止启动，保留原文件。
- 界面串行提交编辑；切换列表、导出、隐藏、退出前先确认当前编辑已保存。
- 页面开启上下文隔离和 Chromium 沙箱，不开放 Node.js；便签文字按纯文本显示，CSP 阻止页面联网和执行内联脚本。
- 本机图形驱动与旧透明窗口存在兼容性问题，因此默认关闭硬件加速。

开机启动是 Windows/macOS 系统集成选项。源码模式记录当前源码路径，移动项目后应关闭再重新开启。Linux 的自动启动请通过桌面环境配置。

## 验证与打包

```sh
npm run check
npm run lint
npm run format:check
npm test
npm run test:desktop
npm run build:dir
node test/desktop-smoke.cjs --packaged
```

`test:desktop` 真实启动 Electron 并操作界面，使用独立测试目录。覆盖创建、自动保存、撤销、排序、完成和恢复、旧数据导入、Excel、穿透开关、隐藏和二次启动、重启后数据和窗口尺寸。

在 Codex 的 Windows 隔离执行环境中，Chromium 的嵌套沙箱可能导致子进程无法启动。仅在该测试环境下，可先设置 `$env:OFFICE_TEST_NESTED_SANDBOX='1'` 再运行桌面测试；测试会传入 `--no-sandbox`，并在结果中记录此限制。普通启动入口不使用该参数，窗口仍默认启用 Chromium 沙箱。开机启动集成在测试中使用替身核对系统调用参数，不会修改真实开机启动设置；实际登录启动需在系统登录时验证。

`build:dir` 使用已安装的 Electron 二进制打包到 `outputs/desktop/win-unpacked`。该目录需要整体保留，不能只复制 exe。打包版不要求目标电脑安装 Node.js。

代码使用 ESLint 推荐规则检查未定义变量和未使用变量，Prettier 统一格式，`.editorconfig` 统一编码和缩进。修改后可执行 `npm run format` 格式化源码，再运行检查和测试。

如需 Windows 安装包：

```sh
npm run build:installer
```

安装包、macOS/Linux 跨平台发行、签名、公证需要相应平台环境及发布配置；当前验证目标为这台 Windows 电脑。

## 自动更新配置

本应用重新实现了更新流程，不能使用原作者的更新源。默认没有发布服务器，因此会明确显示“尚未配置更新源”。不会将原作者的程序作为更新下载覆盖本项目。

发布自己的新版后，在打包版 exe 同级放置 `update-config.json`：

```json
{ "url": "https://your-server.example/office-notes/" }
```

服务器需提供 electron-builder 生成的 `latest.yml`、新版 NSIS 安装包及相关 blockmap。更新源只能使用 HTTPS。检查成功后自动下载，下载完成由用户确认安装；安装前保存当前内容。源目录内提供 `update-config.example.json` 作为示例。

首次版本尚未发布到服务器，因此远端检查、下载和安装链路不能作为已联网验证的功能。
